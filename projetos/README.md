# 📚 Sistema de Notas

Sistema de gerenciamento de notas desenvolvido em **Python** como projeto de prática de programação.

O programa permite cadastrar alunos, calcular automaticamente a média das notas e visualizar a situação de cada aluno.

## 🚀 Funcionalidades

* Cadastrar alunos
* Inserir 3 notas para cada aluno
* Calcular a média automaticamente
* Identificar a situação do aluno:

  * ✅ Aprovado
  * ⚠️ Recuperação
  * ❌ Reprovado
* Visualizar todos os alunos cadastrados
* Encerrar o sistema pelo menu

## 🛠️ Tecnologias utilizadas

* Python 3
* Listas
* Dicionários
* Estruturas condicionais
* Estrutura de repetição `while`
* Laço `for`
* Entrada de dados com `input()`
* `f-strings`

## 📌 Regras

A situação do aluno é definida de acordo com a média:

| Média         | Situação    |
| ------------- | ----------- |
| 7,0 ou mais   | Aprovado    |
| 5,0 a 6,9     | Recuperação |
| Abaixo de 5,0 | Reprovado   |

## 💻 Exemplo

```text
====== SISTEMA DE NOTAS ======

1 - Cadastrar aluno
2 - Visualizar alunos
3 - Sair

Escolha uma opção: 1

Digite o nome do aluno: Eduardo
Digite a nota 1: 8
Digite a nota 2: 7
Digite a nota 3: 9

Aluno cadastrado com sucesso!

Média: 8.0
Situação: Aprovado
```
